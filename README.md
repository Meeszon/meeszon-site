# meeszon-site

My personal portfolio, styled as a retro desktop. The home page is a browser window on that desktop — project case studies open as their own draggable windows, and a portrait in the corner follows your cursor like it's making eye contact.

Built with React and Vite. The gaze effect is pre-rendered rather than ML at runtime — a set of portrait frames quantized into a grid and swapped based on cursor position.

See `CONTEXT.md` for the vocabulary used across the codebase.
